# 🎮 Speed Quiz Obby

Bem-vindo ao **Speed Quiz Obby**, meu primeiro projeto no Roblox! 🚀

Esse jogo mistura **quiz**, **obby** e **competição de velocidade** em uma experiência divertida e desafiadora.

Seu objetivo é simples:

👉 Termine o quiz e os obbies o mais rápido possível para aparecer no ranking dos melhores jogadores!

---

# 🧠 Sobre o Jogo

No **Speed Quiz Obby**, os jogadores precisam completar desafios de perguntas e fases de obstáculos enquanto correm contra o tempo.

Cada fase concluída recompensa o jogador com 💰 moedas, que podem ser usadas para desbloquear:

* 🗺️ Novos mapas
* 🔥 Fases mais difíceis
* 🎯 Novos desafios
* 🏆 Mais progresso no jogo

Quanto mais rápido você terminar, maior será sua posição na tabela de ranking!

# 💸 Sistema de Progressão

Ao completar cada obby, o jogador recebe moedas.

Essas moedas podem ser usadas para:

* Desbloquear novas fases
* Acessar desafios mais difíceis
* Evoluir dentro do jogo

Quanto mais você joga, mais conteúdo consegue desbloquear!
